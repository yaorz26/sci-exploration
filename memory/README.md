# 项目辅助记忆

根目录 `PROJECT_MEMORY.md` 保存当前必须知道的压缩状态；本目录保存次一级细节，避免主记忆无限增长。

| 文件 | 内容 | 何时更新 |
|---|---|---|
| `project-contract.md` | 目的、目标、范围、红线、成功标准 | 项目目标或约束变化时 |
| `research-findings.md` | 已验证发现、失败方向、问题和不确定性 | 得出或修正研究结论时 |
| `decisions-and-next-steps.md` | 用户决策、停止/继续理由、下一步门槛 | 方向或执行状态变化时 |
| `artifact-map.md` | 入口、协议、报告、数据、模型和代码位置 | 新增/移动重要文件时 |
| `user-requirements.md` | 用户提出的行为要求（提问方式、文档归档、版本登记、自用文体、记忆处理细则） | 用户提出新要求或更改要求时 |
| `dialogue/` | 2026-10-02 之前的逐轮对话记录 | **已停用**：只读归档，不再更新（2026-10-02 用户要求移除该功能） |
| `<主题>.md` | 按主题承接主记忆压缩后移出的细节 | 主记忆压缩时 |

记忆文件不是证据。出现冲突时，依次以原始机器输出、冻结实验协议、正式报告、`.research-state`、本目录记忆为准。
