## 三个候选研究点（按风险从低到高）

1. 粒度不匹配：函数边界 ≠ 语义 subtask 边界；复杂题动态细化到分支、循环或语义阶段。
2. 结构化反馈：异常类型 + 失败测试摘要 + AST/控制流特征。
3. 过程奖励的适用边界：弱生成器 + 小样本下，学习评分器为何不如直接用 public pass rate 选择（已有数据，最安全）。
