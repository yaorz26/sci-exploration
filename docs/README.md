# 实验仓库文档入口

这里放“怎么做”和“为什么这样做”的人类可读文档。机器结果不要在这里重复粘贴，优先链接到 `reports/`、`data/processed/` 和 `.research-state/`。

## 文档分区

- `plans/`：执行计划和下一阶段计划。计划文件原来放在仓库根目录，现已集中到这里。
- `../reports/`：按日期和实验阶段命名的正式结果报告。
- `../experiments/`：每个实验的预注册、预算、冻结切分和状态。
- `../.research-state/`：跨会话恢复用的当前状态和追加账本。

## 阅读顺序

1. 先看工作区级总览：[研究总览_当前结论与后续方向](../../docs/week2/研究总览_当前结论与后续方向.md)。
2. 再看本仓库 README，了解运行环境和旧的 CodePRM 基线。
3. 针对具体实验，先读 `experiments/<实验名>/preregistration.md`，再读对应报告。
4. 最后查看 `data/processed/` 中的机器结果和 `scripts/` 中的分析脚本。
