# 问题A的评测协议候选 v0.2

本稿取代15号文档v0.1中的切分重排、因果表述、题目独立抽样及失败归因建议；旧稿保留。它是执行前候选协议，尚未登记为正式实验，不包含新模型结果。

主问题仍为：在相同的题目—方法总token预算上限下，阶段依赖、共享状态、独立可测程度与拆分相对整体生成收益有什么关系？这里“关系”指当前样本中的关联，不要求识别结构因素的因果效应。相同上限允许实际用量不同，实际花费须另报；不能叫作实际成本相等。

## 数据、切分与贡献范围

保持initial20 v5的11开发/9储备及仓库隔离。开发为boltons/cachetools，储备为more-itertools/confuse。两种方法在同一道题上比较，因此来源固定；按来源隔离也有助于检查向未参与方法调试的来源迁移。不能仅因来源与切分重合就判定配对比较无效，或重新打乱储备题。

来源、行为复杂度和结构仍可能一起变化。因此分层成绩只能说明当前样本组合的关联，不能分离每个因素的贡献。4来源、9储备题不足以支持稳定的多因素回归或普遍边界。当前20个细分家族各1题不等于必须补重复题才有效；还须按清单中的related_families处理相关任务，缓存等家族不能被当成多次独立证据。

数据集贡献定位为：保留来源和适配轨迹、只固定外部solve入口、内部helper可自主设计、可执行的行为测试、与成绩分开收集的结构证据及可追踪成本。FEA-Bench提供新增函数/类接口；FeatureBench包含从零实现和接口约束。独立功能、项目来源、接口明确等属性本身不构成新颖性。当前候选主要是轻量库功能，不能代表完整项目集成或全部项目功能级开发；题目保留，论文范围须明确这一适用层级。

## 标注与评分

v3审查员包只含需求、公开例子、通用定义和两份空表，管理映射单独保管。两位未参与构建、未见作者初标/源码/隐藏测试/模型成绩的人类独立填写；原始表先保存，一致性先计算，再协商分歧另存。模型或合成测试表不算人工。

unknown作为有效类别保留，另报双方均有明确判断的覆盖数。报告各字段原始一致率、κ、边际分布及分歧；零方差时κ不可定义。不能通过事后删unknown提高一致性，也不以一个任意κ阈值代替语义质量判断。是否可独立测必须给出至少两个用途不同的行为及输入/输出/独立验证理由；这仍是需要人类审查的证据，不是客观真值证明。

每题每臂一个预定候选。Y_i为全部公开和隐藏测试均通过，Δ_i=Y_i(M2)-Y_i(M0)。主表报告配对胜/平/负、整题通过数/总题数及平均Δ；按全部预定题计分。预算不足、计划解析或组装失败算该臂未通过，并单列失败阶段；API或评测基础设施故障单列测量异常，不与模型行为错误混写，整轮有效性须重新审查。

M0完整实现，允许自行写helper；M2先计划2—3个helper，按依赖实现再组装入口。这是所比较的特定分解流程，不能代表所有拆分方法。记录函数约束及每个阶段原文，不能只存异常消息后推断算法根因。

## 严格总预算与证据保存

计费口径为所有预检与生成请求的prompt_eval_count+eval_count之和，包括重复提示和单token预检输出。登记预算上限、上下文、模型版本/量化、temperature、seed、每阶段输出上限、超时和最大调用数；尚未为正式实验锁定数值。

旧探针的6500只约束生成请求，不能直接沿用其效果结论作为严格总预算结果。若继续使用预检，必须在预检发出前验证有足够额度容纳预检本身；预检之后仍要留足重复输入及生成输出的额度。无法事前保证计数上限时应使用经过核验的本地计数或保守上界，不得先超支再把token裁掉。预检与真实请求计数不一致须记录为预算异常。

每次请求先保存完整prompt、选项及哈希，返回后立即保存原始响应、计数与时间，随后解析；这样失败阶段也可复核。所有题目和两臂候选、生成失败及预算账本全部冻结后才读取private评分。public用于题面，不做候选筛选/重试；储备题成绩不得用于更改协议。

正式前先完成零模型调用的模拟预算与失败路径验证，再用开发题做有明确调用上限的端到端烟测。模拟检查不能冒充真实端到端烟测。当前执行器仍按旧生成预算工作，未经更新和验证不得启动正式运行。

## 分析与启动条件

开发集成绩只作探索；储备集在协议及标签冻结后才作迁移描述。分别报告逐题、逐来源和相关家族组件的结果，包含分母和空格。主报告不用把20题当独立同分布样本的bootstrap区间；只有4来源时来源聚类区间也不稳定。优先列配对结果与留一来源/相关家族的敏感性，不以脆弱的显著性支持普遍结论。需要可靠外推区间时另行扩大来源覆盖并预登记，不在本次小样本上硬拟合。

开始模型评测前必须满足：真实双审完成并解决需求缺陷；数据、标签和协议版本冻结；总预算执行器、失败证据保存和private延后访问验证通过；开发烟测有完整计量；预定任务清单与分析方法登记。无需为此重排现有储备切分，也没有“每结构格至少4题便自动有效”的充分规则。

如果整题收益未出现且花费更高，写成“本流程在这些题上未显示整题收益，实际成本较高”；若出现分层差异，写成“当前样本的探索性关联”。接口失败与低收益可以同时观察，不能未经消融就说接口成本导致或抵消了收益。

当前仍缺真实双审和严格总预算执行验证，正式评测未开始。下一阶段可自主推进执行器证据保存、预算拒绝和模拟故障验证，不必等待人工才能做这些独立工作；不继续旧配置模型扩量。
