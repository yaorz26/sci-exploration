# P15：候选测量证据及来源内支撑

未知：将global拆成具体行为约束以后，现有题库能否支撑跨来源、跨家族的结构关联分析？竞争解释：20题足以在不同来源复现某种约束；或重要约束集中在单一来源/相关组件，直接汇总会把题数当成独立证据。

最低区分检查：只读取原manifest、P12已保存成对证据、P13组合实验摘要、P14输入计量和既有家族组件。产出20题管理端附加记录，将原初标、候选实体/观察、行为证据、未测/不适用、预算情景与家族分开。8题有成对操作性证据；其余12题不以未检查冒充无干扰。C04两个实体尺度分别登记。

按来源和既有关联组件统计容量干扰、全局顺序、有限未见干扰、单实体不适用的实际支撑；原初标另列交叉表。用精确有理数计算描述性设计矩阵的秩与零空间，只诊断完全别名，不拟合模型成绩或统计显著性。缺乏重叠和完全别名是不同问题；15显式组件不是独立样本数。

决策影响：若支撑集中则先补不同来源/家族的具体行为证据，而非扩大相似题；新增候选保持独立扩展池，不重排现有开发/储备，不将构造反例作为真实人类标注。附加记录仅管理端，不能直接作为盲审包、模型提示或新的正式结构真值。
