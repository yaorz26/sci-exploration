# P40：原20题的前置比较支撑很窄

按86号预先固定的严格规则——同来源、目标轴不同、其余两轴完全相同——原20题只有依赖集合1对、状态范围2对、独立可测程度0对。原储备9题三轴均0。该结果限制分别解释各轴的设计，不否定按当前任务组合描述联合关联，也不把严格标签匹配强制变成主问题A的新必要条件。

41个同来源对中，3对三轴全部相同，3对只差一轴，19对差两轴，16对差三轴。任务对共享端点，不能把190或41当样本量。四来源各只属于一个切分，开发/储备的差异也伴随来源变化，不能解释为同来源的新样本确认。

依赖集合唯一对是B03/B06：direct对branch_rules+direct，均none/no，跨原显式组件及宽敏感性群，但不同功能、题面和难度仍不受控。这不是有序阶段依赖强弱的一组干净对照；删除B03或B06就失去全部此轴严格支撑。

状态范围两对是C01/C04、C02/C04：global对partitioned，均operation_sequence/partial。没有none对有状态的严格对比；两对同属缓存显式关联组件，删除这个组件后全部消失。不能把两对当两个独立来源或独立复现。

独立可测程度不仅在同来源严格匹配下为0：20题的8种依赖集合各自只对应一种testability，即在这份作者初标中，testability可由依赖集合查表完全恢复。这个样本事实尚不能说明定义在一般任务上必然如此，也不能判断是否由标注程序直接生成；后者是下一项具体未知。

原15显式组件，追加既有tree_traversal等宽敏感性关联后14组件。唯一依赖对仍跨宽群；状态两对仍在同群，结论不变。跨组件并不保证真实独立。

## 阶段审查

学到：在现有粗编码与固定切分中，三轴共同变化比单轴变化常见，独立可测维度与依赖集合完全对应。排除：不能仅据总题数、先前具体行为矩阵满秩或已有各类别，就声称三个主维度各有跨来源、跨组件对比。仍未知：标签对应是否来自编码规则、真实语义机会还是任务挑选；新测量附件能否改善独立记录；A实际收益仍未验证。

严格集合匹配可能遗漏语义相似但标签不同的题。有对也不保证公平匹配，没有对也不证明不可分析。主A可继续报告逐题配对、联合结构组合与来源/群敏感性，但不得拆成三个因素各自的效应或因果。当前结果不触发重排11/9切分、增加模型预算或把扩展混入原20。
