# D1-P6：独立复核与正式评测准备

用户授权继续沿上轮结论推进。题目与主问题A不变；不新增被测模型生成，不购买资源，不训练、不RL、不发布。当前20题307用例为候选，人工结构判定为0。

本阶段以零生成调用完成：检查盲审材料是否真正不泄漏作者信息，建立独立双审表和一致性分析入口；从已有机器账本重算计量开销、核对失败证据是否完整；审查开发/储备与来源、家族、结构的交叉分布；补读最接近基准的一手方法材料；写出正式协议候选和明确的启动门槛。

输入：initial20 v5、盲审包v2、两轮成本探针、相关工作来源矩阵。角色由当前助手承担，复核属于非独立第二遍检查；不能冒称人类或独立真值。实际人工双审须由未参加题目构建、未见源码/初标/隐藏/模型成绩的两位人类独立完成，当前无可调用人类审查服务，先把可交付包及验收程序做全，不虚填。

预算：本地审计和脚本运行合计最多30分钟；新增Qwen生成调用0，保留既有约91/100；在线一手检索最多12次工具请求、下载最多10MiB，单请求30秒，失败最多一次替代入口。只读已有冻结数据/模型输出，修订材料另存版本。

退出条件：盲审包隔离检查、空表拒绝检查、一致性数学边界检查完成；成本及结构交叉表有机器证据；源材料实际阅读范围/失败记录明确；协议列出预算定义、评分分母、缺失处理、来源混杂和不准启动的条件。

失败条件：任何计量或盲审泄漏缺口不掩盖，生成原文缺失不能补造；没有人工表不能计算真实κ，没有结构覆盖不能宣称可识别三个因素的边界。阶段审查后另做方向审查，选择继续质量补齐、定向补样或停止模型扩量。
