# P32：可结合的信息摘要及两个不足接口

F03的二元最终值归并失效可以用明确中间信息修复。本轮候选摘要逐节点保留最高优先级首原值、所有候选是否为对象，以及仅在全部为对象时的递归子摘要。缺失为单位元；提供的null有自己的值摘要。组合保留来源先后顺序，不要求跨操作可变共享状态。

新程序在216个已保存输入上，两种括号所得摘要216/216相同，432个最终值全部与P31已保存的多层结果相符；六个新手算包含嵌套类型门槛、缺失、null、数组、空对象，12个终值符合。六种值的左右单位元和单值最终化共18项通过。参考/另一实现再次调用0，模型/API0。这里432是新摘要最终值，不是新增参考调用，不是432个独立任务。

两个事先冻结的碰撞给出更强的接口边界。P=[{a:1},{b:2}]、Q=[{a:1,b:2},{}]都得到合并值{a:1,b:2}、全对象标记true、候选数2；追加0后必须分别为{a:1}和{a:1,b:2}。因此即使再加候选数，“合并终值＋标记”也不足。P=[{a:1},{b:2}]、Q=[{a:1},{}]的首原值、标记、数量相同，但正确最终值不同；“首原值＋标记”缺少递归贡献。这两组固定碰撞2/2被候选完整摘要区分；不是证明唯一最小字段集。

一般论证依赖一个不变式：摘要描述某一节点实际存在候选的有序串。首原值是该串第一个元素；标记是所有元素为对象的合取。若标记为真，每个子键的摘要描述该键实际存在值的有序子串；为假则整节点按首原值覆盖，不再需要子递归结果。两个非空有序串连接后，首元素取左侧，标记取与，子串按同样顺序连接；空串为单位元。因此按有限JSON树深度归纳，合法摘要的combine描述串连接，串连接结合，摘要组合亦结合；finalize恰好实现公开多层规则。此论证限于合法摘要、固定优先顺序及声明JSON域，不承诺任意伪造摘要或来源交换。

该表示复制首对象和部分递归信息，没有内存效率、token效率或最小性结论。算法运行时摘要也不等于模型提示token。P31意外读取隐藏输入描述的限制延续，不能将本轮对照称为未见储备验证。

问题A的含义：任务侧可以记录“候选全集合的路径类型门槛”，具体计划侧则记录是否保留其所需信息。无跨操作状态不足以说明阶段可任意连接；局部组件正确也不足以说明其输出接口适合继续组合。P33继续区分整对象级一个标记和每路径标记，随后换到另一家族的信息接口，避免无限扩同类格。
