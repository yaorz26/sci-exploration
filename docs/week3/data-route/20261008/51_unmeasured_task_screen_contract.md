# P23：原未测任务能否补足结构支撑，还是测量范围本就不同

具体未知：P15剩余12个未测原任务，有没有非缓存的跨实体依赖、另一来源的操作历史全局顺序或明确不适用案例，能够改变现有支撑？竞争解释：缺口只是未做测量；或公开任务语义/输入域不含所需现象，扩同类不能解决，需要分清任务适用范围。

第一动作从P15保存附件获得12个任务编号，仅抽取其公开需求、原家族/来源/切分与明确类型。未测不改成负值。先写筛选证据，不按模型成绩选题、不读隐藏选择候选。候选最多两题，在允许域内固定目标观察，明确改变哪个实体/历史；没有第二实体、没有顺序输出或不存在操作历史就记问题不适用/尚无见证，不能补成无依赖标签。

最低成本验证优先用公开例子或保存参考求值；只有确有新问题才执行新成对输入。如需新的输入，先冻结手算投影和竞争解释，参考/另一结构在公开允许域交叉运行；状态主张不能由错误程序或聚合观察虚假通过，沿用P18/P21边界。探针不计307、作者初标/人工表不回写，储备只作管理端需求证据核对、不生成/调参模型。

预算本地25分钟、模型/API/下载0、公开需求12题、最多两题新探针/最多40关系，两次实质尝试无新增证据换路。不以筛选数量当贡献；明确能否补缺、哪条解释被排除才进入审查。若候选域不足，转原任务输入域/隐藏用例覆盖的具体缺口，而非继续无限扩缓存。研究后自主启动下一项。
