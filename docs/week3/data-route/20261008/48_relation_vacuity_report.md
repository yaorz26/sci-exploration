# P21结果：有限隔离关系可以被错误恒定输出满足

一份基本形状和类型合法、但call恒定返回0且计数/缓存尺寸恒定为0的C04错误程序，通过了全部103条相等关系：102条其他实例动作插入关系及1条手算实例隔离关系。然而它在这些关系及两条阳性关系的210次输入求值中，绝对输出与保存参考匹配0/210；历史依赖、同实例不同键淘汰两条阳性关系均失败。相等关系通过不意味着实现正确，甚至基础形状、类型及输入不变门槛都无法排除这个反例。

第二个程序始终抛ValueError。若比较错误标签，它也“通过”103/103条相等关系；执行有效性门槛会把全部105条关系记为不可测，而不是隔离证据。不能删除这些失败再只报剩余关系通过率。
