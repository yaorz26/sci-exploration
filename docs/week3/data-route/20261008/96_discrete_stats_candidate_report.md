# P44：离散输出能形成清楚的局部契约，但仍只是候选

为绕开P43的浮点精度冲突，固定同一 boltons `Stats` 模块的两个离散输出：`count`（样本数量）和`mode`（出现次数最多的值）。契约明确限定输入为有限、可哈希的整数或字符串列表；空列表的count为0，mode返回题面给定的default；并列时返回首次出现的值。

6个冻结输入覆盖普通整数、字符串、首次出现并列、空列表、重复零和负数。整体实现和两个helper实现各通过6/6，共12/12；一个错误的并列规则实现通过5/6，在首次出现并列输入上被拒。总18个本地比较，不是模型生成、人工审查或全域正确性。

这排除了“两个字段无法分别观察”的简单解释：它们有不同用途，也能分别给出逐值结果。它没有证明它们是无依赖的——两个输出共享同一输入，mode还依赖并列规则。它也没有补足P40的来源和样本支撑缺口：仍是boltons单一来源，候选标签不写回原20。

P44阶段结论：离散输出候选比E_B08的mean/variance更适合作为后续数据集扩展，因为不需要把任意浮点容差偷偷加入评分器。下一步先不继续增加统计函数，而检查原开发集的联合结构画像能否支撑主问题A的描述性关联；若画像单元几乎被来源/相关组件锁死，应先报告适用边界，而不是启动模型评测。
