# P42：不同统计用途提供契约机会，但不能从源码定阶段次序

非缓存扩展研究候选E_B08采用固定boltons Stats的均值和总体方差。公开文档分别说明中心位置与离散程度，确有不同用途、输入及输出契约。两种标准库方案可先均值再方差，或用两两差公式先方差再均值；任务不要求唯一的均值先算次序。这是任务侧机会的有限证据，不是已经填好P40独立可测标签空格。

## 实际验证及更正

首探针为6个公开输入、每个新建Stats对象并取得两属性；预期来自独立代码中写出的公式，而不是事前手算真值，不能据此称“人工6个锚点确认”。原机器输出用“手算式”及“variance实现语义依赖mean”过强，保留原文件，并在补充冻结文件中明确更正：源码调用只说明实现依赖，不证明外部任务义务。

补充验证复用6份上游结果，只执行两种新标准库方案各6次；另1个事前冻结输入[0,2,4]执行上游及两新方案，共15次新程序求值。原6输入的分数解析值为事后回查，新增1输入属于契约允许的额外小域输入；未使用300格枚举预算。21个结果单位含6复用，不写成21全新。

预先声明的局部诊断规则是有限浮点、绝对差不超过1e-12，无相对差。21/21结果单位符合解析分数对应数值；这是诊断符合率，不是原评分或模型通过率。两种计算次序在实数/有理数域的等价来自恒等式：

`sum(i<j)(xi-xj)^2 = n*sum(xi^2)-(sum xi)^2 = n*sum(xi-mean)^2`。

因此variance可先算而不读取mean输出。共享原输入不自动否定局部行为机会；组合有效域和数值精度仍需明确。

不同用途还由两组解析对比支持：[1,2,3]与[0,2,4]均值同为2、方差2/3与8/3；[1,2,3]与[100,101,102]方差同为2/3、均值2与101。某一个输出不能恢复另一个输出，不把两个展示字段自动当两个独立行为或独立样本。
