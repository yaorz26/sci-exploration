# P39：新的测量边界与已有功能级评测研究

具体未知：现有FEA-Bench/FeatureBench等一手研究是否已经同时区分任务侧结构、生成后计划/组件参与、输出可观察单位，并在任务—方法总token预算下分析拆分关联？竞争解释是新反例只重述已有完整测量框架、现有工作覆盖部分边界但未把它们用于同预算关联设计、或当前D1证据不足以提出可检验的新贡献。

最低成本验证：先读取已存官方来源与17号方法证据索引，不重复旧方法段结论；明确新需要的具体段落/变量：输入/输出token统计口径、内部helper自由度、任务属性与计划属性的采集时间、异常/数据标记/投影分母、组件使用或结果贡献指标。对最多三篇一手论文官方HTML/仓库文档定向核对，缺少某指标须写“在所查方法/附录未发现”，不写穷尽否定。论文全文获取不冒称全部读完；按来源保存链接、章节与简短证据摘录、访问日期，不保存大段全文。

预算25分钟、最多三源/六相关段、模型/API/付费/下载模型与数据集/隐藏评分0、两次不可达尝试后换可用官方来源。可联网读论文页面，计为文献获取，不能冒称全程零网络。任务输出不是首创成对测试/程序依赖/动态切片；竞争解释若显示已有完整框架，就收窄到公开功能适配、具体反例与协议验证贡献，不硬造新术语。

阶段退出：对新测量主张给覆盖/未证/差异表与影响D1下一步的判断。完成按证据选一种有信息收益的实施，不只继续扩大文献或反例数量；保持人工冻结/资源与真实效果不足限制。
