# P43：浮点候选无法仅靠小样本选定唯一精度规则

已用P42保存的一个等价算法差异和9个明确控制值，比较三种规则：逐位相等；有限数上的绝对/相对误差 `max(1e-12, 1e-12×最大绝对值)`；有限数输出先按12位小数、银行家舍入后再比较。没有运行Stats或旧任务，只比较保存值。

十个比较包括：等价算法差异、完全相同、1与1.0、布尔与数字、增加1e-3的明显错误、极小量、大数小相对误差、大数明显相对错误、NaN、Infinity。结果是：逐位相等拒绝等价差异；后两种候选规则都接受等价差异，拒绝1e-3错误，并拒绝非有限值。

这个结果区分了“精确规则过严”和“宽松规则一定正确”两种解释，但没有为1e-12或12位提供语义依据。比如只差4e-13的结果，两种宽松规则都可能接受；若任务要求逐位复现，这可能是错误。反过来，逐位规则又会把合法的不同计算顺序判成错。故不能把局部诊断容差推广到原20，也不能把E_B08的某一规则称为正式协议。

阶段结论：P43完成了数值边界诊断，E_B08保留为研究候选、三个结构标签仍为null。它不适合作为当前D1正式比较样本，除非另行冻结数值域、有限性、精度和误差的任务契约，并经过独立审查。为避免在任意阈值上继续消耗，下一步改查同一公开模块中的离散统计量，寻找没有浮点容差争议的候选。
