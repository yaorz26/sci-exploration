## 可以直接核实的两种失败

M0重放第一个公开输入，IndexError发生于candidate.py第10行，j已等于字符串长度。条件是j < len(text) and text[j].isalnum() or text[j] in ' ;'，or右侧仍会访问text[j]，导致越界。仅确认这个公开输入的错误触发点；其他隐藏不匹配仍不能统归为此原因。候选未修补，没有新成绩。

M2计划固定_is_ansi_code(char)、_is_ansi_sequence(text)。第二helper响应却同时定义两个函数，重写已冻结的_is_ansi_code；生成检查按已登记约束拒绝组装，未生成入口、未进行行为评分。该响应done_reason=stop，输出91低于256，不是长度截断。原文/AST说明本次撞名，不证明所有拆分/提示策略都无效。不能自动删掉重复函数再作为原首候选成绩。

P8短128输出烟测已单独保留生成失败，P9为新工程额度，不能作为未见确认或同协议复跑。储备题无被测生成/评分；当前人工结构标签仍0。
