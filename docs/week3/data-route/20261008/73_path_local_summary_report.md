# P33：整对象级标记不能代替路径信息

两个前缀P=[{x:{a:1}},{x:0}]与Q=[{x:{a:1}},{}]的最高优先级首对象、合并终值、整对象全对象标记、来源数均相同。追加同一个{x:{b:2}}后，P因x已出现非对象而必须保持{x:{a:1}}，Q则必须返回{x:{a:1,b:2}}。区别位于x节点，而不是来源列表顶层。

冻结的x路径碰撞、outer/x嵌套碰撞都得到不同续接值；追加无关y的控制得到相同续接值。三个裁剪的整对象投影均相同，三个完整摘要的相应路径标记均为false/true。六个新最终值全部符合手算，旧216格/旧参考再次执行0、新隐藏读取0、模型/API0。使用的是P32保存的合法摘要程序，不以完整程序自己的结果冒称独立参考。

这排除了“首原值与终值已隐含全部路径阻断”及“一个整对象全对象标记足够”的具体接口假设。它没有证明必须采用此唯一表示；保留整个来源序列、其他等价摘要也可能合法。无关y控制说明相同投影不自动导致所有续接都不同；不足见证的量词是存在一个允许的续接。

F03至此形成闭合贡献：局部二元正确但归并失败、明确摘要修复、信息碰撞说明两种删减不足、路径观察单位决定接口义务。停止扩展相似格和摘要字段，下一项换M05研究：一个接口丢失行身份时，入口若仍能访问原输入，是否可通过重计算救回？这将区分“限定接口不足”与“任务不可分解”，防止把本轮结论过度推广到方法效果。
