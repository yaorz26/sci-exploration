# P44：离散统计量能否作为无浮点歧义的候选

具体未知：固定boltons Stats的`count`和`mode`能否形成两个用途不同、输出可逐值比较的任务侧契约，并允许内部采用整体实现或两个helper实现？这一步针对P43发现的浮点精度障碍，仍服务于主问题A中的“可独立验证程度”，不宣称新候选自动适合正式数据集。

竞争解释：count和mode只是同一个整体结果的两个字段；它们分别表示样本数量和出现频率最高的值，能在明确输入域内独立验证；mode的并列规则、空输入默认值或非数字类别会让契约仍含糊。需要把并列和空域列为显式边界。

最低成本验证：只读固定Stats公开源码/docstring，冻结输入域为有限、可哈希的整数/字符串列表；冻结count为空为0、mode为空使用给定default、并列返回首次出现值。构造两个合法实现（整体一次返回；两个内部helper分别计算）和一个明显错误对照，在最多6个输入上用原`json_equal`逐值比较。若两合法实现全通过且错误对照被拒，说明离散输出可减少数值观测歧义；仍不能证明内部拆法收益或人工标签可靠。

预算25分钟、一个固定功能/最多6输入/3个实现、模型/API/下载/原测试/private读取0，两次实质修订。扩展候选另池，原20/307/11—9不变；不按结果给原题补标签。如果并列或空域无法清楚冻结，保留失败并换路，不扩大同类统计量。
