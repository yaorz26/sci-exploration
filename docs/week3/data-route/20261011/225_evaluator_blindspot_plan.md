## 目标与定义

用真实结果构造两个合法候选：`C`=control（旧8项8/8，新入口0/1），`F`=complete（旧8项8/8，新入口1/1）。旧评价`Y_old`只看原8项；修订评价`Y_full`同时看原8项和直接入口。对两个候选的两种臂分配分别计算`Δ_old=Y_old(M2)-Y_old(M0)`与`Δ_full=Y_full(M2)-Y_full(M0)`。M0/M2这里只是位置标签，不是模型输出或真实方法归因。

## 步骤

1. 从四份已保存结果读取`all_pass`/`passed`，不运行工作区。
2. 形成两个分配：M0=C、M2=F；M0=F、M2=C。对每个分配给出旧评价和完整评价的Y、Δ、符号变化。
3. 输出公式、输入证据hash和限制：只有一个任务、一个补充入口、二元完整通过指标；不能外推真实方法错误率或统计显著性。
4. 依据结果更新G4协议说明：先冻结明示API行为锚点，再谈同预算相对收益；若无符号变化则保留No-Go。
