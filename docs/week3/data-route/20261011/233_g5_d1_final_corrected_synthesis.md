# D1 阶段性成果最终纠正版

本文件取代 `230_g5_d1_boundary_synthesis.md` 中关于本地模型资源边界的旧表述；真实项目候选、PR126评价器反例和所有原始实验目录均保留。

## 已形成的成果

第一，PR126、PR142和PR440已形成可复查的真实项目研究池候选：每项保留父源码、公开需求、公开行为评价、来源关系和未解决边界。它们仍是 `research_pool_only`，没有正式切分、正式结构标签或真实人工双审。

第二，PR126的契约反例证明旧评价器可能误收明示 API 不完整的实现：控制实现旧评价8/8，但直接 `YamlSource` 新入口0/1；完整和独立组织各1/1。新增证据只支持“接口验收覆盖不足”，不能填充共享状态或阶段依赖标签。

第三，本地 Qwen2.5-Coder:7B 的真实项目生成已完成计量纠正后的批次。固定行段遗漏已修复为完整 AST API 上下文；三题 M0/M2 共发送11次请求，已知服务端总消耗23380 token，本地 tokenizer 与服务端输入计数逐次一致，每臂6500预算严格执行。M0三题均未形成可应用补丁（两次 hunk 原行不匹配，一次写出包外路径）；M2三题均在计划和组件之后因剩余预算不足而事前拒绝组装。没有候选进入行为评价。

## 结论边界

当前证据支持：真实项目任务和评价入口可复查；某类旧评价的 API 覆盖存在盲点；在冻结的模型、提示、完整 API 上下文、严格补丁入口和每臂6500总 token 组合下，没有取得可评价候选。

当前证据不支持：M0或M2的行为准确率、主问题 A 的 `Δ`、拆分相对整体的收益、三种结构因素的正式标签、模型总体效果、人工一致性或因果解释。无候选时行为准确率分子未定义，不能把结果写成0/6准确率。
