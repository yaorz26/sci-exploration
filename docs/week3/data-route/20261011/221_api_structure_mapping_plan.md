### 可行性

### 意义与重心

若把“多入口”直接加入结构轴，会重演过度评测。修订：结果只服务于“接口覆盖 vs 结构unknown”的证据分层，不新增题目、不扩大测试、不改变主A分母。通过：结论可直接改写数据集适用边界。

### 区分力与可信度

源码调用链相似不能证明运行时同一状态所有权；反之，控制的故意分叉不能当自然结构差异。修订：报告只陈述可见源码路径和运行结果，不声称因果、独立性或全域等价；若三组织内部链路不同，结构字段留unknown。通过：能排除“接口覆盖缺口自动等于结构轴”的解释，未被排除的替代解释保留。
