# WP3 冒烟协议（预注册，ClassEval）

日期：2026-09-29 ｜ 状态：**已在运行前冻结**（结果见 `03_smoke_report_classeval.md`）
依据：`docs/week3/9.28数据集路线_分步执行与Agent移交文档.md` §八（WP3）与 §八.4（门槛）

## 一、目的

不测模型效果，只回答：**这批题能否在本机稳定自动判分**，以及**按方法切分公开/私有测试是否可行**。

## 二、抽样（看结果之前冻结）

| 项 | 规则 |
| --- | --- |
| 抽样池 | ClassEval 全部 100 题（Hugging Face `FudanSELab/ClassEval`，MIT） |
| 分层依据 | `methods_info` 的**方法数量**：≥5 → 目标层（高可拆分）；==3 → 边界层；==2 → 负对照层；==4 → 不进本次抽样 |
| 抽样 | `random.seed(20260929)`，各层分别抽 4 / 3 / 3 题；抽中后按 task_id 排序，**事后不得更换** |
| 重复 | 每题连续 3 次，要求 3 次结果一致 |
| 通过判定 | 子进程退出码为 0（unittest 全过） |
| 失败处理 | 全部如实记录，**不得用其他题替补**；原因归类（缺依赖 / 算力 / 环境语义 / 非确定性 / NumPy 版本） |
| 公开/私有切分 | 按 `methods_info` 顺序，前 ⌈n/2⌉ 个方法的测试类为**公开**，其余及无法映射者为**私有**；两侧都必须含 `def test_`，否则该侧判为不可用 |

## 四、门槛（引自执行文档 §8.4，WP0 未另行修改，按此执行）

- 10 题中至少 **8 题**能在干净环境完成安装与测试；
- 至少 8 题参考实现**连续 3 次结果一致**；
- 至少 8 题不依赖外部网络、人工交互或真实云服务；
- 预注册的 4/3/3 分层配额均有明确入层理由；
- **每层静态储备 ≥8 个**可用任务 ID；
- 至少 8 题能放进冻结的输入长度预算；
- 能建立严格的公开/私有测试隔离方案；
- 许可证与来源信息覆盖全部 10 题；
- 所有新增数据、环境与缓存按 WP0 约束落盘（D 盘）。

**门槛失败时不得通过删除失败题来凑够比例**；可另立 v2 协议，但必须保留 v1 的失败记录与修改原因。
