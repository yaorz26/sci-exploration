# P72：已有行为证据能否形成结构比较行（完成）

## 具体未知与竞争解释

主问题 A 不是只问“某个题能不能拆”，而是问阶段依赖、共享状态、独立可测程度与拆分收益之间的关系。已有 initial20 只有单人预标，因此本阶段把 D1_B01、D1_B03、D1_B05、D1_C03 的公开契约和已保存行为证据整理成四条证据行，检查它们能否形成可比结构对照。

竞争解释有三种：

1. 已保存反例和有限执行足以形成依赖、状态、可测的结构证据行，并能找到同条件的一轴对照；
2. 行为证据只能说明局部输出义务或接口条件，不能变成任务固有标签；
3. 旧题虽然结构描述不同，但来源、切分和多个轴同时变化，不能用于主问题 A 的正式比较。

## 最低成本验证

只读 initial20 manifest、P57 B01、P54/P55 B03、P62 B05、P20 C03 报告和已保存结果。每题建立 dependency_claim、shared_state_claim、testability_claim、evidence_status、见证计数、适用范围和证据路径；不修改 manifest 的正式结构字段。随后枚举四题的 6 个配对，要求同来源、同切分且只有一个结构轴变化才算正式一轴对照。

## 原始结果

四条证据行全部建立：

- D1_B01：固定 sorted(expand(payload)) 接口下，多重集合契约可检出错误，强局部顺序会误拒整体合法逆序；6/6 正常整体、逆序整体，强局部逆序 3/6，去重控制 1/6。
- D1_B03：单次清理和原始区间接口在有限锚点上可连接；两类串行删除各 5/6，原始区间接口 12/12、局部区间 24/24。原题没有明确 single-pass，因此证据状态只能是 partial。
- D1_B05：物化后扫描和原树按实际乘积先选均 6/6；除法逆阈值 5/6，路径映射 6/6，说明值与路径是依赖边，但不规定唯一物化次序。
- D1_C03：三种合法实现分别把持久状态放在入口、单个 helper 或两个 helper 之间；原案例各 33/33，有限序列 2343 条、程序求值 7029 次，第三方案共享状态轨迹 6/6。

六个配对中只有 3 个同来源同切分（B01/B03/B05），但它们的依赖轴和可测轴同时变化；其余 C03 还跨来源。最终 formal_one_axis_contrast_count=0。因此，四条证据行支持“局部机制边界”的数据集字段，却没有产生可用于回答主问题 A 的正式结构对照。

## 结论与下一步

本阶段排除了“把已有题目的结构字段和行为反例拼在一起就足以比较结构因素”的解释。当前缺口是数据设计缺口：需要新增或重构最小控制配对，固定来源、切分、任务规模和两个结构轴，只改变一个轴，并为每个配对预先定义整体、局部和序列证据。下一阶段只做控制配对设计和可行性筛选，不增加模型调用、不读取 private、不修改 initial20 或正式标签。
