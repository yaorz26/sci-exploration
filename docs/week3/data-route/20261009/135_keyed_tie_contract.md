# P64：来源允许的并列代表与单一精确预期

具体未知：如果未来将minmax候选扩为key=abs，公开规范不承诺首次最大项，那么固定来源实现与两遍builtin方案是否会返回不同但合法的最大代表？以来源输出作唯一精确预期会不会额外固定实现内部的并列选择？这关系数据集外部真值的独立性和内部自由拆法，服务主问题A的可靠计分前提。

竞争解释：不同程序仍返回相同原整数，无需更改比较语义；或并列最大键时不同原整数都符合公开规范，单一参考精确比较过度约束；或同键不足以证明合法，因为输出还须来自输入、字段类型与最小/最大key必须正确。当前E_M07整数无key候选不受该扩域影响，未来variant仅研究，不修改原数据或候选域。

最低成本：事前冻结四新精确整数列表，两组唯一最小/并列最大键、一组唯一极值、一组非零唯一极值。来源minmax(key=abs)与builtin min/max(key=abs)各四次，共8solve/来源4调用；事前分别推演来源配对扫描与first选择的输出。正常域直接按公开语义检查输出整数属于原列表、绝对值分别达到min/max键，不固定并列最大代表。四个最小键均唯一，避免扩猜来源未明示的最小并列选择。仅此两程序，零旧六例/原测试/private读取。

决策：若相同停止扩表；若合法输出不同，保存精确参考误拒见证，下一步限定实现成员与极值键规则，而不按某程序多数改原预期。正式适配是否选择first或允许并列代表须明确增量，不能悄悄默认。人类0/标签null/模型效果未知。
