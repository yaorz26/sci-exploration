# P57：区间展开的局部顺序是否由整体任务决定

具体未知：B01要求最终升序且保留重复，其“区间展开/全局排序可分别测试”的作者初标为yes。如果为展开helper设置“按文本片段顺序、区间方向输出”的局部测试，会不会拒绝整体合法方案？任务侧可测机会与指定局部序列契约必须分开，这关系主问题A的独立可测变量口径。

竞争解释：最终任务也决定展开helper的中间次序，逆序helper会使整体失败；或最终排序只决定展开的数值多重集合，合法局部顺序有多个，强顺序测试会过度约束；或多重集合测试太弱而漏掉丢重复的整体错误。无论结果如何，不用本阶段更改原初标，也不声称做到了完整的独立可测标注。

最低成本：先冻结公开B01题面哈希、六个新合法锚点及两个非法数值锚点的逐值预期。新写三种结构：按片段顺序展开后排序；展开结果整体逆序后排序；去重展开后排序的错误控制。每个程序仅在每锚点执行一次，捕获该次执行的helper实际返回/异常，同时比较强顺序与弱多重集合契约；不得为局部检查再调用helper。合法锚点包括重复、反向闭区间、空片段、多字符分隔符及空文本，全部公开诊断而非新增隐藏集。错误锚点只观察ValueError，不能把相同拒绝当局部正确的证据。

判断改变：若合法逆序方案整体通过而强局部失败，新增测量需记录局部契约与整体任务的蕴含关系，不能把一种helper次序作为任务固有阶段；若弱契约能检出去重，保留其信息价值。证明理由是排序在原值多重集合上的不变性，而非把有限锚点称完整证明。
