# P76：第二来源组内上下文候选

具体未知：同组中一项的值改变后，是否会改变同组其他项的归一化结果，而保持另一组不变？这补充主问题 A 的结构覆盖：它把“必须看同组上下文”与“每项独立处理”区分开来。它仍是候选任务证据，不是拆分收益或正式结构标签。

竞争解释：H1 同组最小值是共享上下文，修改同组一项会改变同组其他项的结果；H2 每个值独立变换，只有被修改项变化；H3 聚合实现把各组混在一起，另一组也会变化。

最低成本验证：六个事前手算输入、整体递归/分函数/固定来源 `more_itertools.map_reduce` 适配各六次，共18次solve。E_M08需求：`items`是有序 `{group,value}` 列表，group为字符串，value为精确整数；按组首次出现顺序输出。每组用本组最小值作base，对原序每个值计算 `normalized=value-base`，`total=sum(normalized)`；只返回total≥threshold的组，每条恰含group、normalized、total。空输入返回groups=[]，不改输入；长度≤16、整数绝对值≤32、threshold∈[-16,64]，只要求合法域，内部结构自由。

六锚点：A=`a:[3,5],b:[7,9],threshold=3`；B只把a的3改为1；C只把b的7改为5；D单组`a:[4,4],threshold=0`；E空列表；F=`b:[-2,1],a:[2,5],threshold=3`。A/B用于同组干预，A/C用于另一组控制；D/E覆盖重复值和空域；F覆盖负值与首次出现顺序。预期：A空；B只返回a(normalized[0,4],total4)；C只返回b(normalized[0,4],total4)；D返回a([0,0],0)；E空；F返回b([0,3],3)和a([0,3],3)。

来源证据：公开 `more_itertools.more.map_reduce`（固定提交 `81c21a8db1c922260cd673841257fb9b112c1318`，MIT许可），只读公开源码和许可，不读测试或储备题。源API提供按key聚合及reduce，不规定本任务的输入输出包装或内部调用次序。与现有M04有分桶相关性，不能称第五独立来源或独立样本。
