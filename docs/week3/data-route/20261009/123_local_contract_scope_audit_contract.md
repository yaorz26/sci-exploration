# P58：局部测量是否隐含指定拆法

具体未知：现有证据能否支持“凡有可执行局部测试，就可直接作为任务固有的独立可测证据”？还是需要记录约束从哪里来、在哪种接口下才必要？主问题A要关联任务结构和方法收益，若指定拆法的要求被记为任务属性，会混入额外约束。

竞争解释：现有局部预期都由任务题面必然推出；或至少存在整体合法但违反强局部预期的反例，需要分开任务输出义务和条件于接口的义务；或未冻结的候选/观测时机根本不足以判定必要性，不能仅依据程序互证补标签。

最低成本：事前固定六条主张及其已有原始证据路径，零新任务求值。逐条回查B01强顺序与多重集合、B03类别原区间、E_B09数量整数类型与众数default类型、E_B10每前缀EOF快照。记录`contract_origin`、`necessity_scope`、证据见证与未知项，直接以保存输出/公开题面检验，不重新执行正确程序/评分器/模型。不读取原隐藏测试，不追改初标，不把助手整理当人工复审。

决策：如有合法反例，就另存协议增量候选，要求局部失败同时报告其约束来源和接口条件，不计为任务固有缺陷；原协议和旧分母仍保留。如所有约束均题面必然，停止增加字段。规范不足的行留unknown，不以新增名词替代证据。
