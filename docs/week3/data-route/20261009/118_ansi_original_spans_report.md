# P55：原始区间接口使类别拆分可合法连接

复用P54六输入/来源输出，只执行两个新的区间接口入口：先short/先CSI各6/6终值通过，共12新solve，24实际helper调用；24/24局部区间符合本阶段执行前逐字解析预期。源码来源新求值0、原四结构/私测/模型不重跑，输入保持。原机器证据`experiments/d1_ansi_original_spans_v1_20261009/`保留两程序、事前区间/代码哈希、worker原始轨迹和summary。

两个纯helper均读原串，分别返回半开匹配区间；入口将区间标记后一次保留未标字符。调用先后改变不再改变待匹配文本。此前两个字符串中间结果连接各有失败，不足以说明按两种码类分解不可行；接口保留原始位置就能满足单次解释。

有限结果之外的语法理由：完整码内部字符的允许ASCII范围都排除ESC，故一完整码不能包含另一匹配的起点；短码第二字排除`[`，同位置不能同时为CSI。因此两个类别在原串上的完整区间不重叠，区间并集一次删除与单次匹配对应。这是明确语法下的论证，不是机器形式化证明、最小接口或唯一分解。

边界：同助手局部预期非真实人工双审；12程序执行非实际M2生成/预算成绩。任务的跨操作状态初标不改，输入版本约束不能自动改写为shared state；原B03尚未明说单次，原20/307/切分/旧模型分数保持。

阶段审查：合法原区间连接获有限证据，源码给出一般理由；规范明确性仍待澄清。方向审查：停止增加ANSI坏串或接口方案，P56仅核对原两个公开例子能否区分一次与重复清理，并给未来单次措辞候选。只用已保存六输入/一次二次结果、公开例子，不重新执行或读取隐藏；不得用公开例子不区分就冒称人类确有歧义。
