# PR440之后的新问题三轮深挖与审核

上一问题的可见结果：PR440在有限回调域补充了非缓存组生命周期任务；官方/独立组织3/3，延迟归约控制关键2例失败。新增任务与PR126路径来源、PR142环境来源、cache过期报告的机制不同。G3增量表虽已生成，但程序纠正要求不把事后表冒称事前审定。

## 第一轮：从证据找未知，核对来源和重复

证据显示：PR126是来源元数据→Filename读取，PR142是环境/YAML→Configuration读取，PR440是外层groupby推进→已归约结果。三者都能写成“前一步结果影响后一步观察”，但外部对象、历史语义和控制不同；将这句共同描述直接当作“阶段依赖”会把接口数据流、来源优先级和迭代生命周期混为一类。cache又有公开读触发清理的测量副作用，不能当同一观察机制。

具体未知修订为：**能否构造一份跨候选的最小观察维度矩阵，明确哪些维度具有共同外部证据，哪些必须任务特有/unknown，从而不把不同机制误填为同一正式结构轴？**这不是新任务搜索，也不是统计样本扩充。来源只用已保存原始结构/行为证据和PR公开元数据；不读private/test，不重跑行为。

## 第二轮：机制、边界、替代解释与可证伪性

竞争解释A：有共同维度（输入/操作历史改变后续公开结果、可定义最终行为验收），矩阵能支持任务筛选和未来配对；B：共同文字只是抽象比喻，真实依赖机制不可比；C：矩阵实为参考实现/接口条件的编码，不能作生成前结构；D：观察副作用和来源/家族共变让共同维度不可辨认。

最低可证伪证据不是再跑案例，而是逐候选回答同一组问题：是否有外部输入/操作历史、哪一观察在下一调用后改变、是否有旧行为保持控制、合法组织共享哪种外部结果、内部状态/所有权是否未知、观察是否会改变对象、来源机制是否共变。若某字段只能由参考私有成员或同一实现得到，必须标unknown；若只有两个候选出现也不写独立轴。若所有候选在任一共同维度上都只靠抽象叙述，结论应否决“跨任务共同结构矩阵”而转为任务特有边界。

## 第三轮：信息收益、资源、风险与路线选择

继续扩G2会增加来源共变，不提高可比性；继续做cache时点会重复已知副作用；模型比较资源不足且不能回答结构可比性。一次只读矩阵构造成本低，却能决定G4是否有合法的比较单位，并保留“无法比较”这一否定结果。它不增加正式标签，不重跑行为，也不包装新任务。选择该问题：先213号计划三审，再构造一份可复核矩阵和否决字段；矩阵完成后若跨维度仍不可比，G4只保留任务级协议而不估计结构关联。

选择理由：直接推进主问题A的适用边界，且能利用已保存PR126/PR142/PR440原始证据；失败同样能排除“把不同机制硬拼成一轴”的解释。下一步是213号宏观G3/G4边界计划，执行前不得先写矩阵结论。
