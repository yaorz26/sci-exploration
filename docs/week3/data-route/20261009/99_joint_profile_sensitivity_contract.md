# P46：联合画像是否依赖单一来源或关联组件

具体未知：开发11题的3个重复联合画像，在删除任一来源或显式关联组件后是否仍保留？这决定主问题A是否只能逐题报告，还是可以增加有限的画像层敏感性描述。

竞争解释：重复画像跨来源和组件，删除任一方仍有支撑；重复画像跨来源但被某个显式组件完全承载；画像重复本身不稳，删除一个来源就全部消失。第三种结果不能被总题数掩盖。

最低成本验证：复用P45已冻结的manifest/family输入哈希，针对开发11题的每个重复画像，分别移除一个来源、一个显式组件和一个宽敏感性组件，重新计算剩余题数、重复画像数和每个画像的来源/组件覆盖。全20作为参照，储备只报告不用于开发结论。不读取测试/private，不计算成绩。

预算15分钟、最多20行/开发重复画像，两次修订；若所有画像均对删除敏感，停止画像层扩展，改写适用边界；若仍有稳定重复，只保留描述性敏感性，不做独立样本或因果估计。
