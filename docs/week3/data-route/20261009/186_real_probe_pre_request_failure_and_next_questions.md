## 第二轮：机制与可证伪结果

N3追问：一个TTLCache把所有缓存行为委托给同包内部缓存对象，公开输出/容量/时点均相同，但外层Cache基类存储为空；原评价是否会将其拒绝？若会，是任务要求了继承内部存储，还是评价额外假定了所有权？需求只规定外部行为及调用完成清理，没有规定用父类哪个容器。不能只用手工代理的口头等价证明合法，应同时实际检验公开返回、剩余键/值、len/currsize及完成时点，保留范围限定。

public len/currsize会自动expire，可能把延迟实现洗成正确。修订验证输入：采用原boundary_mixed，a在0、b在2插入，timer固定在2，显式expire(4)；观测时间2早于a过期4，公开观察不会自动清理a，故可在消费前检查清理时点。对比完整、委托、仅报告、延迟生成器四种新工作区，不扩随机输入格。
