# P55：类别接口保留原始区间是否足够

具体未知：P54失败是否需要放弃按两类拆分，还是将两helper的返回改成原串匹配区间、入口一次按区间删字符便能保留单次语义？这是D1内部自由拆法/计划信息义务，不能凭不安全的字符串中间结果判任务不可拆。

竞争解释：两类原串区间有冲突，类别组合仍不能复现单次扫描；或保持原始坐标便足以修复两个顺序；或仅样例符合但无一般理由，不能扩成唯一/最小正确方案。

最低成本：复用P54六输入及保存来源终值；执行前冻结每类12组原始半开区间逐值解析预期。两个新入口分别先short/先CSI调用相同纯helper，均在原串查找，入口标记区间后一次输出未标字符。每种六solve，共12新solve/24实际helper调用/24局部区间比较；不重跑原四结构、二次来源、私测/模型。两个helper的正则各仅处理自己的类别，保持标准库/内部结构自由；不要求此为唯一分解。

预算15分钟、六输入两连接次序、最多两修订；模型/API/下载/来源新求值/旧测试/private0。成立时给非重叠完整码的语法理由，但不冒称全字符枚举/形式化验证；失败保存改查最小有冲突区间。完成转B03需求澄清的可审查候选与记录适用范围，不扩相似缺陷数量。
