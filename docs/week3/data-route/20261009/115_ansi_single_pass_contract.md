# P54：原始文本删除与两类控制码的阶段连接

具体未知：B03公开ANSI字符范围加固定来源的单次regex.sub，能否按短ESC码/CSI码两类分别删除后顺序连接？每类局部正确可能在第一次删除后制造新完整码，导致第二阶段删除原来不存在的匹配。它检验无操作状态任务的输入版本义务，及“局部可测”不等任意阶段连接安全。

竞争解释：删除幂等且两阶段次序均等价；或者接合出新码导致非幂等，两个阶段次序各有失败；或者独立扫描器与固定来源不同，需先厘清需求/适配而不能判计划缺陷。原题未显式写“单次左到右非重叠匹配”，此解释来自来源sub和保留未完整片段；若获反例只作为未来需求澄清候选，不追溯改原题或宣称模型根因。

最低成本：先冻结B03公开task/来源模块/ANSI_SEQUENCES及strip_ansi源码哈希与六新逐值预期。四结构各六新solve：上游、独立ASCII扫描器、CSI再短码、短码再CSI；额外只对保存上游六输出执行一次strip_ansi，共24结构求值+6二次来源查询，实际来源strip调用12。六域为普通控制、常规码、删除CSI创造短码、删除短码创造CSI、同类接合、原不完整码。后两测试不泛化全部字符语法，不执行原307/模型或读取curator/private。

预算20分钟、六输入30评价单位、最多两修订，模型/API/下载/旧测试/private0。扫描与来源不符就保存失败转规范修订；证据明确后优先构建保持原始区间的自由接口候选，不扩大量ASCII枚举。B03仍原初标不动，旧P9失败不由此重归因，主A效果未证。
