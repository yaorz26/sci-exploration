## 三、任务结构

1874 题 / 117 仓库 / 10 个领域（如 Internet、Database）；13 名开发者标注，含**需求、原始仓库、参考代码、参考依赖**。任务单元是**函数体**，提供三种上下文设置（无上下文 / 同文件上文 / 上文+下文），为"仓库级代码生成"设置。

**可拆分性判断**：`【推断】` 与 EvoCodeBench 同级——有仓库上下文，但交付单位是单个函数体，题内无多阶段接口。
