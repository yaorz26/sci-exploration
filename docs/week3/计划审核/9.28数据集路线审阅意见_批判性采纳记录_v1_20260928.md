## 一、总体处理原则

审阅指出的“问题线丢失、统计结论过度乐观、环境约束没有落地”三条主批评成立，已进入执行版 v2。但审阅仍然是第二意见，不是新的实验协议；其中的推测、示例阈值和候选数据集名称必须经过 WP0--WP3 验证，不能直接当成事实。

## 三、v2 的关键变化

1. 从“数据任务流水线”改为“研究问题—文献缺口—数据—实验”的证据链。
2. 明确最可靠产出是可复跑的数据和评测基础设施；20--30 题只给探索性信号。
3. 加入“不确定”正式出口，禁止把没有足够证据写成“基本持平”。
4. 把可拆分性分层、生成方式、选择规则和随机种子分开报告。
5. 在完整数据检索前增加 FAST-0，在完整方法比较前增加 P0 候选池探针。
6. 把 Docker / WSL2 / 网络 / C、D 盘限制变成候选数据的硬核查项。

## 四、仍需用户或导师决定

1. 是否接受本路线主要产出可能是基础设施与探索性信号，而非统计上可靠的一般结论。
2. 数据用于评测、训练拆分器、训练生成器还是训练评分器。
3. 数据集本身是否作为正式成果。
4. 新数据下允许使用的结论标签。
5. 是否授权 P0 的少量生成；该授权不自动开放 WP6、训练或强化学习。
6. 若任何 WSL / Docker 组件无法放到 D 盘，是否允许例外；在明确决定前默认不允许。
