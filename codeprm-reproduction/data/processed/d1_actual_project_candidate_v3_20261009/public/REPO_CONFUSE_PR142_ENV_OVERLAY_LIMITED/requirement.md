# 环境变量进入项目配置的有限功能任务

任务来源：beetbox/confuse PR142 的公开功能说明。给定直接父提交 `cd1db04b07db00050900d2f548baf144bb92d261` 的非测试包源码。在真实 `confuse.Configuration` 对象中增加显式选择的环境变量配置来源，使配置文件与环境变量能够共同决定最终的配置读取结果。内部模块划分、辅助函数、字典构造方式均自由。

本候选只保留 PR 的有限子范围，不要求完成 PR142 的所有选项。合法输入域是：指定前缀的环境变量名；剥去前缀后非空且无父子键冲突的普通字符串键；`__` 表示嵌套；值为不含集合语法的有效 YAML 标量；普通映射型配置文件。列表转换、完整 YAML 文档值、重新加载、空键和冲突键均未纳入。

公开功能义务：

1. 支持显式添加环境变量来源，不在构造配置对象时默认加入。匹配前缀的变量才参加配置；剥去前缀后的键转换成小写，`__` 映射到嵌套键。
2. 标量类型转换应与现有 YAML 文件来源一致，例如 `42` 成为整数。最终通过已有配置视图的 `get` 读取，不另建 JSON 求解入口。
3. 在文件来源之后显式加入的环境变量来源具有更高优先级；未被环境变量提供的键仍可由较低优先级来源读取。
4. 没有匹配环境变量时，现有配置值保持不变。

任务构建者固定的外部调用入口是 `Configuration.set_env(prefix, sep='__')`，用于把环境来源放在当前最高优先级。这个入口是候选调用约束；不要求采用 PR 的内部类、工具函数或文件布局。其具体内部组织不是答案。

来源说明：前缀、键名转换、嵌套、标量转换和显式选择来自公开 PR 说明；最高优先级入口是任务构建者为现有 `set`/`set_file` 约定选定的调用约束。评价材料、合并版本和手写控制不属于未来模型可见输入。
