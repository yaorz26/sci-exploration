# 数据目录说明

这里的数据按“来源”和“是否经过处理”分层。数据文件很多，但不建议靠文件名猜用途；先看实验协议和对应报告。

## 三层目录

- `raw/`：从 APPS 或本地来源取得的原始题目，尽量不改写。
- `splits/`：固定题目成员资格和 public/private 切分规则。
- `processed/`：候选、续写、标签、选择结果、私有后评测和审计结果。

## 重要规则

- `private` 测试可以在训练阶段作为标签来源，但不得进入 prompt、public 选择或确认集调参。
- 处理结果一般用 JSON/JSONL 保存；每个正式实验应在 `experiments/` 记录输入、seed、预算和输出文件。
- 不覆盖旧文件。协议变化使用新的日期、版本或 seed 后缀。
- 很大的 JSONL 不适合直接人工阅读；使用 `scripts/` 下的分析脚本生成摘要。
