# P5b Seed43 实验必要性与合理性审查

## 审查对象

拟议实验是对冻结 60 题切分重复运行 seed43 的 M0、M1、M2a、M2b。目标是满足原协议中的双 seed 稳定性要求，并决定是否进入 RL。

## 已有证据

- 困难自然可分解层 M0：选择后私有全通过 `1/20`，池 oracle `1/20`。
- 困难自然可分解层 M1：选择后私有全通过 `0/20`，池 oracle `0/20`。
- 困难自然可分解层 M2a：选择后私有全通过 `0/20`，池 oracle `0/20`。
- 困难自然可分解层 M2b：选择后私有全通过 `0/20`，池 oracle `0/20`。
- M2a/M2b 的输入 token 和结构化请求成本明显高于 M0/M1，且候选损失主要来自结构验证失败。
- 结果、原始摘要和池 oracle 均已保存，测试 31/31 通过。

证据来源：
`reports/p5b_stratified60_seed42_analysis_20260918.md`、
`data/processed/p5b_hard20_*_seed42_v1_summary.json`、
`data/processed/p5b_hard20_*_seed42_v1_pool_oracle.json`。

## 必要性审查

### 对 RL 决策的必要性

不必要。现有决策门要求困难层 M2 同时在选择后私有全通过和池 oracle 上超过 M1，并且两个 seed 的方向一致。seed42 已经显示 M2a/M2b 均为 `0/20`，没有正向信号：

- seed43 若继续为负，只会重复 No-Go 结论；
- seed43 若转为正，也会与 seed42 的方向不一致，仍不能通过“两个 seed 方向一致”的门槛；
- 因此无论 seed43 结果如何，按当前预注册规则都不能合理地启动 RL。

### 对科学解释的必要性

有限但不是当前优先事项。seed43 可以估计结果稳定性，但不能修复已观察到的主要瓶颈：M2 在困难 stdin 任务上的结构协议失败和候选池损失。若没有新的协议、模型或预算假设，重复相同实验的信息增益很低。

## 合理性审查

原实验设计本身合理：切分冻结、公共选择与私有评测分离、stdin 主入口固定、候选成本有记录、池 oracle 后置计算。seed42 执行也没有改变这些规则。

但在当前决策阶段继续 seed43 存在三个问题：

1. 成本高：M2 每层约 200 次实现请求，困难层单个模块化协议的输入 token 已超过 29 万。
2. 决策不可逆向改善：seed43 不能把 seed42 的失败改写为稳定优势。
3. 可能造成伪进展：仅为满足形式上的双 seed 数量而重复同一已暴露的协议瓶颈，不能回答新的机制问题。

## 决定

**不启动 seed43 正式生成实验。** RL 保持暂停，当前结论标记为“在 seed42、当前模型/提示/预算/切分/本地 evaluator 下的 No-Go；双 seed 稳定性未估计”。

只有在研究问题发生明确变化时，seed43 才值得重新考虑，例如：

- 先修复并预注册新的结构协议，再评估协议修复是否改变候选形成率；
- 更换模型或显著增加预算，并把它作为新的实验而不是重复 seed；
- 需要单独估计 seed 方差，并接受其不能改变当前 RL 决策门的事实。

## 下一步

1. 将当前结果、成本和 No-Go 决定归档为中文正式报告。
2. 保留 seed43 未执行的限制，不把 seed42 结果表述为双 seed 确认。
3. 若继续研究，优先设计低成本的协议修复审计或错误归因实验，而不是重复完整生成。
