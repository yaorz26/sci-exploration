实现计划：

1. **count 方法**：
   - 使用组合公式 C(n, m) = n! / (m! * (n - m)!) 计算组合数。
   - 返回计算结果。

2. **count_all 方法**：
   - 使用 2^n 计算所有可能的组合数。
   - 如果结果大于 2^63-1，返回 float("inf")。
   - 返回计算结果。

3. **select 方法**：
   - 调用 _select 方法，传入初始参数。
   - 返回生成的组合列表。

4. **select_all 方法**：
   - 调用 select 方法，传入不同 m 值，生成所有可能的组合。
   - 返回所有组合的列表。

5. **_select 方法**：
   - 使用递归生成组合。
   - 通过递归调用自身，逐步构建组合。
   - 将生成的组合添加到结果列表中。

实现顺序：
1. 实现 count 方法。
2. 实现 count_all 方法。
3. 实现 _select 方法。
4. 实现 select 方法。
5. 实现 select_all 方法。
