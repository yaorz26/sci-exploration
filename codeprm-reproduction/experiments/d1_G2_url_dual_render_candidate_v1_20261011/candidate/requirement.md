# URL 渲染双用途的有限功能任务（降级版 v4：构建者自定义契约）

## 资格声明（2026-10-11 依据实测降级）

本任务**不是**对 `boltons.urlutils` 真实行为的复刻。经固定输入实测，上游 `boltons` 的行为与本任务规则表在四处不一致（证据见同目录 `probe_upstream_render.py`、`upstream_render_probe.json`、`upstream_mapping_probe.json`）：

| 维度 | 上游 boltons 实测行为 | 本任务 v3 规则 |
| --- | --- | --- |
| 查询串中的 `+` | 解码为空格（`a+b` → `a b`，两种渲染都如此） | 视为字面加号 |
| 已有 `%XX` | 最小引用下**解码**（`a%20b` → `a b`）；完全引用下重新编码为 `%20` | 两种渲染都原样保留 |
| 重复键取值 | 类字典视图/`items` 取**最后一个**；`getlist` 给出全部 | `get` 取第一个 |
| 映射视图 | 会解码（`a%20b` → `a b`、`a%2Fb` → `a/b`） | 不解码 |

实测一致率：最小引用 7/18、完全引用 15/18、两者都一致 **6/18**。

**因此本任务的资格降为：构建者自定义的 URL 编码契约（合成任务）**，保留在 `research_pool_only`，但：

- **不得计入"真实项目功能"候选**；在候选统计中单列为合成任务；
- 其"公开需求"来源改写为"任务构建者按 RFC 3986 保留字符集合自行定义"，不再声称来自 boltons 的公开功能说明；
- 其余四个候选（PR126、PR142、PR440、QUEUE_K2）不受影响——它们各自的来源仍是真实仓库变更。

## 一、任务定义（构建者自定义契约）

给定一份 URL 解析/渲染代码，实现一个**有限域**的 URL 对象，使同一次解析既能按"给人看"的方式渲染，也能按"发到网络"的方式渲染。内部是否复用 `urllib.parse`、是否自写正则、辅助函数与模块划分均自由。

## 二、映射视图的取值口径（本契约规定，非上游行为）

查询串映射视图返回**原文片段**，不做百分号解码、不把 `+` 还原成空格：

- `?q=a%20b` → `get('q')` 返回 `a%20b`（不是 `a b`）
- `?q=a+b` → `get('q')` 返回 `a+b`（不是 `a b`）
- 重复键：`keys`/`items` 按出现顺序给出全部条目；`getlist` 返回全部值；`get` 返回**第一个**值。
- **缺键返回值**：`get(key)` 缺键返回 `None`；`get(key, default)` 缺键返回 `default`；**`getlist(key)` 缺键返回空列表 `[]`**（不返回 `None`、不抛异常）。

## 三、两种渲染的精确规则（逐字符）

| 字符类别 | 具体字符 | 显示 `to_text()` | 发送 `to_text(full_quote=True)` |
| --- | --- | --- | --- |
| 未保留字符 | `A-Z a-z 0-9 - . _ ~` | 保留 | 保留 |
| 子分隔符 | `! $ & ' ( ) * + , ; =` | 保留 | 保留 |
| 路径/查询/片段分隔符 | `/ ? : @` | 保留 | 保留 |
| 空格 | U+0020 | **保留** | **编码为 `%20`** |
| `%` 且后接两位十六进制 | 例如 `%20`、`%2F` | **整体保留**（3 字符） | **整体保留**（3 字符） |
| `%` 且后接非两位十六进制 | 例如 `100%off`、`%`、`%zz`、`%2` | **编码为 `%25`** | **编码为 `%25`** |
| 其余 ASCII 可打印 | `" # < > [ \ ] ^ ` { \| }` | **编码** | **编码** |
| 非 ASCII | 例如中文 | **编码**（UTF-8 逐字节） | **编码**（UTF-8 逐字节） |

**判定优先级（消除重叠）**：`%` 一律先按上表第 5、6 两行判定（看其后是否恰好两位十六进制），**不再落入"其余 ASCII 可打印"行**。因此 `%00`—`%FF` 不存在两种合法输出：构成合法序列者整段保留，否则其 `%` 编码为 `%25`。

原先单列的"已有 `%XX` 不重复编码"与"字面 `%` 编码为 `%25`"两条已并入上表，不再重复，以免与字符表冲突。

3. **组件内 `#`**：编码为 `%23`（它是组件分隔符，不得在组件内原样出现）。
4. 组件之间的分隔符（`://`、`/`、`?`、`#`）由拼装层输出，不参与上述编码判定。

## 四、最小判定例

| 输入 | `to_text()` | `to_text(full_quote=True)` |
| --- | --- | --- |
| `http://h/p?q=a+b` | `http://h/p?q=a+b` | `http://h/p?q=a+b` |
| `http://h/p?q=a%20b` | `http://h/p?q=a%20b` | `http://h/p?q=a%20b` |
| `http://h/p?q=100%off` | `http://h/p?q=100%25off` | `http://h/p?q=100%25off` |
| `http://h/files/report 1.pdf` | `http://h/files/report 1.pdf` | `http://h/files/report%201.pdf` |

## 五、公开调用入口与合法域

固定为下列入口，名称与签名逐字如下：

```python
url = URL("http://h/p?q=a%20b")     # 构造函数
url.to_text()                        # 显示用途
url.to_text(full_quote=True)         # 发送用途

view = url_view("http://h/p?q=a%20b")  # 取查询串映射视图的唯一入口（模块级函数，不是 URL 的属性）
view.keys()                            # -> ['q']
view.items()                           # -> [('q', 'a%20b')]
view.get('q')                          # -> 'a%20b'；缺键 -> None
view.get('missing', 'd')               # -> 'd'
view.getlist('q')                      # -> ['a%20b']；缺键 -> []（空列表，不抛异常）
```

- **映射视图必须通过模块级函数 `url_view(url)` 取得**，不要求也不禁止 `URL` 对象上另设同名属性；评价只按 `url_view(url)` 调用。
- 合法域：以 `http://`/`https://` 开头、普通 ASCII 主机、可含路径/查询/片段。不纳入：userinfo、IPv6、相对 URL、非 ASCII 主机、IDNA。
