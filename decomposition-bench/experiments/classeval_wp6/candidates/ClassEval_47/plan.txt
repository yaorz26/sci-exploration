实现计划：

1. **初始化方法 (`__init__`)**：
   - 将传入的 IP 地址存储在实例变量 `self.ip_address` 中。

2. **验证方法 (`is_valid`)**：
   - 使用正则表达式检查 IP 地址是否符合格式 `xxx.xxx.xxx.xxx`，其中 `xxx` 是 0 到 255 之间的数字。
   - 如果格式正确，进一步检查每个数字是否在 0 到 255 之间。
   - 返回 `True` 或 `False`。

3. **获取八位组方法 (`get_octets`)**：
   - 调用 `is_valid` 方法验证 IP 地址。
   - 如果有效，将 IP 地址按 `.` 分割成四个八位组，并返回这些八位组的列表。
   - 如果无效，返回空列表。

4. **获取二进制表示方法 (`get_binary`)**：
   - 调用 `is_valid` 方法验证 IP 地址。
   - 如果有效，将每个八位组转换为 8 位二进制数，并用 `.` 连接这些二进制数。
   - 如果无效，返回空字符串。

实现顺序：
1. 实现 `__init__` 方法。
2. 实现 `is_valid` 方法。
3. 实现 `get_octets` 方法。
4. 实现 `get_binary` 方法。
